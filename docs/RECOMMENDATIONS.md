# 캐릭터별 AI 추천 입고 구성

시작 덱은 돌 7장·권총 3장으로 동일합니다. 아래는 거래소에 입고할 카드 4종의 추천이며, 입고한 카드는 상대도 구매할 수 있습니다.

캐릭터별 70개 조합을 기본 AI로 각 12판 비교한 뒤, 6개 후보를 모의 실행 AI로 각 24판 평가했습니다. 평가 순으로 첫 구성을 고르고, 그 구성과 최소 2장이 다른 후보 중 두 번째 구성을 골랐습니다. 다른 구성을 찾지 못한 에코는 후보 3개를 추가 평가해 두 번째 구성을 골랐습니다. 선정에 쓰지 않은 시드로 각 추천을 96판 검증했습니다. 검증 결과로 추천 순위를 다시 정하지 않았습니다. 총 14,184판을 평가했으며, 화면의 추천 번호가 확정적인 성능 순위는 아닙니다.

상대는 플레이 가능 캐릭터 12명을 균등하게 포함하고 입고 4종은 무작위입니다. 실제 대전과 같은 중립 2종, 공유 더미 12장 규칙을 사용합니다. 승리 1점·무승부(차례/조작 상한 포함) 0.5점으로 비교했습니다. 기본 AI와 모의 실행 AI는 서로 다른 정책이므로 1차에 탈락한 조합이 더 좋을 가능성도 있습니다. 모의 실행 AI는 상대 차례를 예측하지 않고 자신의 뽑힐 카드 순서를 활용할 수 있으며, 구매 가치표는 기존 조정값을 사용합니다. 결과는 사람 상대 승률이나 모험 모드 승률이 아닙니다. 카드·능력·AI 수치는 변경하지 않았습니다.

새로 재현: `node tools/recommend.js --out /tmp/card-recommendations-fresh.json` (기존 출력 파일이 있으면 완료한 캐릭터를 건너뜁니다). 시드: 1차 312026, 후보 비교 719090, 검증 1047290. 상세 결과: [recommendation-results.json](recommendation-results.json).
